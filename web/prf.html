Passkey test

Does one passkey derive the same keys on every device?

PineSign derives your encryption keys from your passkey, on your device, every session. Nothing is stored and nothing is sent — which only works if the same passkey gives the same answer wherever you use it.

Create a passkey here, then open this page on another device signed in to the same password manager and press Use existing passkey. Every key below must match, character for character.
